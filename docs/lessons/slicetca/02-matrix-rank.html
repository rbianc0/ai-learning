Matrix rank

Rank tells us how many genuinely independent directions are hidden inside a matrix, regardless of how many entries the matrix contains.

Start from Node 1

You already know that a scalar multiple of a vector does not create a new direction. Matrix rank simply turns that idea into a count.

Rank = number of independent directions represented by the rows or columns of the matrix.

For what we need here, think in terms of columns.

Example 1 — two columns, one direction

122436
rank 1
c₁ = [1,2,3]ᵀ
c₂ = [2,4,6]ᵀ = 2c₁

The second column is a scaled copy of the first. It adds no new direction.

Example 2 — a second direction appears

1001
rank 2
c₁ = [1,0]ᵀ
c₂ = [0,1]ᵀ

No scalar turns one column into the other. The matrix therefore contains two independent directions.

Interactive: when does rank collapse?

Start with column 1 = [1,2]ᵀ. Column 2 is built as [k, 2k + ε]ᵀ.

Scale a redundant column

12.024.0
With ε = 0, column 2 = k·column 1 → rank 1.

Break the exact dependence

A = [[1, k],
     [2, 2k + ε]]
ε = 0 → rank 1

As soon as ε is non-zero, the second column is no longer an exact scalar multiple of the first, so the two columns become independent and the rank becomes 2.

Why this matters for the path

Rank measures effective structural complexity, not physical matrix size.

many entries ≠ many independent patterns

A large neural-data matrix can therefore contain only a few independent patterns. That is the idea we will later connect to PCA and low-rank decompositions.
