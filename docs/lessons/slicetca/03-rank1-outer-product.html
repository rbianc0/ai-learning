Rank-1 matrix = outer product

A rank-1 matrix is not just “a matrix with rank 1.” It has a very specific structure: one common pattern is repeated across columns, with only the scale changing.

Start from what rank 1 means

If a matrix has rank 1, every non-zero column points along the same direction.

column 1 = 2a
column 2 = −1a
column 3 = 4a
...

So instead of storing every column independently, we can store:

one vector a = the common column pattern, and one vector b = how strongly that pattern appears in each column.

The outer product is defined entry-by-entry as

Aᵢⱼ = aᵢ bⱼ

But the column view is more useful here:

column j of A = bⱼ · a

The conceptual click

Column 1
b₁a = 2[1,2,3]ᵀ = [2,4,6]ᵀ
Column 2
b₂a = −1[1,2,3]ᵀ = [−1,−2,−3]ᵀ
↓
Both columns are scalar multiples of the same vector a. Therefore the matrix contains exactly one independent column direction → rank 1.

Interactive: change b, keep rank 1

The vector a = [1,2,3]ᵀ stays fixed. Change the two entries of b; every matrix column remains a scaled copy of a.

2.0-1.04.0-2.06.0-3.0

Rank ≤ 1: both columns are multiples of a.

If both entries of b become zero, the result is the zero matrix, whose rank is 0. Otherwise this outer product has rank 1.

Why this representation matters

The matrix

A = a ⊗ b

separates two roles:

a describes the pattern along the rows.
b describes how strongly that same pattern appears across columns.

This is the exact idea we will later extend from a matrix to a three-axis neural tensor.

Keep this sentence: outer product = one pattern on one axis × one pattern on another axis.
