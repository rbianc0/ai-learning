PCA as a low-rank approximation

You already know PCA finds important directions of variation. Now connect that geometric idea to matrices: keeping only a few principal components means replacing the original data matrix by a lower-rank approximation.

Start with a data matrix

Let the columns of a centered matrix X be observations. In neuroscience, a column might be one population-activity observation and each row one neuron.

X = [ observation₁ | observation₂ | ... | observationₙ ]

If the observations mostly lie near one line in neural state space, we can describe each observation approximately using:

one common direction × one scalar score for each observation.

One PC gives a rank-1 reconstruction

Call the first principal direction u₁. Each observation gets a score telling us how far to move along that direction.

scores = [s₁, s₂, ..., sₙ]

The reconstructed matrix using only PC1 is

X̂₁ = u₁ ⊗ scores

From Node 3, you already know what this means: every reconstructed column is a scalar multiple of the same vector u₁.

Therefore X̂₁ has rank 1.

What happens when we keep more PCs?

Each additional principal component contributes another direction and another vector of scores.

PC1
u₁ ⊗ scores₁   → rank-1 component
PC2
u₂ ⊗ scores₂   → another rank-1 component
PC3
u₃ ⊗ scores₃   → another rank-1 component

Keeping k PCs gives

X̂ₖ = u₁⊗scores₁ + u₂⊗scores₂ + ... + uₖ⊗scoresₖ

So the reconstruction has rank at most k (and, in ordinary PCA with nonzero retained components, rank k).

Why PCA chooses these particular directions

We do not choose arbitrary rank-1 components. PCA orders orthogonal directions by how much variance they capture. PC1 captures the most possible variance; PC2 captures the most remaining variance subject to being orthogonal to PC1; and so on.

Geometric view

Find the important directions in the point cloud, then project onto them.

Matrix view

Approximate X by a matrix with only a few independent directions: a low-rank matrix.

Same operation, two viewpoints: PCA projection in geometry = low-rank approximation in matrix language.

The connection we need for sliceTCA

PCA starts with a matrix and represents its structure as a sum of simple rank-1 matrix components:

vector ⊗ vector

Our neural data in the paper will instead have three axes:

neuron × time × trial

That raises the next question: what is the three-axis analogue of a rank-1 outer-product component?
