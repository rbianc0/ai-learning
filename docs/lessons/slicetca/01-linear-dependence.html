Linear dependence

Sometimes several vectors look like several directions, but they actually contain only one independent direction.

A vector can be scaled

Take v = [1, 2]. Multiplying by 2 gives:

2v = 2[1, 2] = [2, 4]

The new vector is longer, but it has not created a new direction. It still lies on the same line through the origin.

Core intuition: changing only the length, or reversing orientation, does not create a new independent direction.

Interactive: same direction or new direction?

Dependent pair

Still only one independent direction.

Independent pair

Two different directions → independent.

The formal statement

Two non-zero vectors v₁ and v₂ are linearly dependent when one can be obtained by multiplying the other by a scalar:

v₂ = c · v₁

For more than two vectors, the general definition is:

c₁v₁ + c₂v₂ + ··· + cₙvₙ = 0

If this can be satisfied with coefficients that are not all zero, the vectors are linearly dependent. Then at least one vector is redundant: it can be reconstructed from the others.

Why this matters

Matrix and tensor decompositions try to describe large datasets using a smaller number of underlying patterns. First we need to distinguish genuinely new directions from scaled copies.

Bridge to Node 2: matrix rank counts how many independent directions are actually present.
