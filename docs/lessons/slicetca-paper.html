Linear dependence

The idea we need before matrix rank is simple: sometimes several vectors look like several directions, but they actually contain only one independent direction.

Start from something you already know

A vector can be scaled

Take v = [1, 2]. Multiplying by 2 gives:

2v = 2[1, 2] = [2, 4]

The new vector is longer, but it has not created a new direction. It still lies on the same line through the origin.

Core intuition: changing only the length (or reversing the direction) does not create a new independent direction.

Dependent pair

Still only one independent direction.

Independent pair

Unless the two vectors become collinear, they provide two independent directions.

The formal statement

Two non-zero vectors v₁ and v₂ are linearly dependent when one can be obtained by multiplying the other by a scalar:

v₂ = c · v₁

For more than two vectors, the general definition is:

c₁v₁ + c₂v₂ + ··· + cₙvₙ = 0

If this equation can be satisfied with coefficients that are not all zero, the vectors are linearly dependent.

Why? Because then at least one vector can be reconstructed from the others. That vector contributes no genuinely new direction.

Why we care for sliceTCA

Matrix and tensor decompositions try to describe large datasets using a smaller number of underlying patterns. To count how many genuinely different patterns are present, we first need to distinguish new directions from scaled/redundant copies.

This is the bridge to the next node: matrix rank = how many independent directions are actually present.
