Node 2

Matrix rank: count the independent directions

A matrix can contain many numbers while still carrying only a small number of genuinely independent patterns.

Rank = number of independent directions represented by the rows or columns of the matrix.

For the matrices we need here, it is enough to think in terms of columns: count how many columns contribute genuinely new directions.

Example 1 — looks like two columns, but only one direction

122436
rank 1

Read the columns:

c₁ = [1,2,3]ᵀ
c₂ = [2,4,6]ᵀ = 2c₁

The second column is only a scaled copy of the first. So the matrix contains one independent column direction.

Example 2 — a genuinely new column appears

1001
rank 2
c₁ = [1,0]ᵀ
c₂ = [0,1]ᵀ

No scalar can turn one column into the other. They point in two independent directions, so the rank is 2.

Interactive: when does rank collapse?

Change the second column. When it becomes exactly a multiple of the first column, two apparent columns collapse to one independent direction.

Why this matters

Rank tells us how complicated a data matrix really is, not how large it looks.

many entries ≠ many independent patterns

A huge neural-data matrix may be approximated by only a few independent patterns. That idea is the bridge to PCA and low-rank decompositions.
